# 🍽️ La Trattoria — Restaurant Landing Page

A dark, elegant restaurant landing page built with vanilla HTML, CSS, and JavaScript.

Live Demo: [ terry-stang92.github.io/La-Trattoria-Restaurant/](https://terry-stang92.github.io/La-Trattoria-Restaurant/)

## Features

- Responsive mobile-first design with hamburger menu
- Hero section with real food photography (Unsplash)
- Animated stat counters (years, dishes, chefs, satisfaction)
- Reservation form with full client-side validation
- Dark luxury aesthetic using CSS variables

## Built With

HTML5 · CSS3 · JavaScript · CSS Variables · Flexbox · Grid
